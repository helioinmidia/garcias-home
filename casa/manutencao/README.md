# Manutenção da casa

Pasta da aplicação de manutenção doméstica, publicada em `http://casa.blizzard.net/manutencao/`.

O cronograma ainda vai ser criado. Enquanto isso, `index.html` mostra só um aviso. Quando o cronograma
estiver pronto (uma página estática, ou uma aplicação com servidor próprio), ele substitui esse
`index.html` ou passa a ser atendido por um `reverse_proxy` no `Caddyfile`, como descrito no README principal.

Este arquivo não é servido pelo Caddy (`hide README.md`).
